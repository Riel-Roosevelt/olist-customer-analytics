# Brazilian E-Commerce Customer Analytics & Retention Dashboard

An end-to-end data analytics and data science project focused on customer retention, behavior segmentation, and lifetime value analysis using the **Brazilian E-Commerce Dataset (Olist)** from Google BigQuery.
---

## Executive Summary

This project analyzes over **96,000+ delivered transactions** to solve key customer retention challenges in an e-commerce platform. By leveraging SQL heavy-lifting in Google BigQuery, exploratory data analysis in Python, and interactive reporting via Streamlit and Power BI, this project provides actionable insights to drive customer lifetime value (LTV) and re-engagement strategies.
---

## Tech Stack & Architecture

* **Data Warehouse:** Google BigQuery (SQL)
* **Data Processing & Analytics:** Python (`pandas`, `numpy`), Google Colab
* **Data Visualization:** `plotly`, `seaborn`, `matplotlib`
* **Web App Deployment:** Streamlit Community Cloud
* **Business Intelligence:** Microsoft Power BI (Executive Report)
---

## Key Analytics & Methodologies

1. **Cohort Retention Analysis:**
   * Tracked monthly user purchase behaviors from first-touch acquisition.
   * **Key Finding:** Identified that over 99% of customers are one-time buyers, highlighting a critical need for structured activation and retention campaigns.

2. **RFM Segmentation (Recency, Frequency, Monetary):**
   * Categorized customer base into distinct operational segments (*Champions*, *Loyal / High Spenders*, *New Customers*, *At Risk*, and *Lost*).
   * Mapped behavioral segments to specific marketing actions.

3. **Historical Customer Lifetime Value (LTV):**
   * Evaluated average revenue contribution per customer segment to prioritize retention budget allocation.
---

## Business Recommendations

* **Champions & High Spenders:** Implement an exclusive loyalty program with threshold-based perks (e.g., free shipping) to maintain engagement.
* **At-Risk Customers:** Deploy automated win-back email campaigns with time-sensitive discount codes to trigger repeat purchases.
* **New Customers:** Optimize the 30-day onboarding journey with tailored product recommendations to increase activation rates.
